MI CHANGUITO — INSTALACIÓN EN iPHONE

Este ZIP contiene una Progressive Web App (PWA), lista para publicar.

1. Publicá la carpeta completa en un hosting HTTPS (por ejemplo, GitHub Pages o Netlify).
2. Abrí la dirección HTTPS de la app desde Safari en tu iPhone.
3. Tocá Compartir / menú de página → Agregar a pantalla de inicio → Abrir como app → Agregar.
4. Abrí Mi Changuito desde el ícono y permití acceso a la cámara.

IMPORTANTE
- Abrir index.html como archivo local NO permite instalar la PWA ni garantiza permiso de cámara.
- El lector de códigos descarga html5-qrcode desde un CDN en el primer uso: requiere conexión a Internet.
- La consulta de precios depende de un servicio público externo no verificado en este entorno; puede no responder o cambiar de formato.
- Los precios son orientativos, regionales y pueden no coincidir con tu sucursal.
- El changuito se guarda solo en el navegador del dispositivo.
- Para actualización de precios es necesaria conexión a Internet.

Contiene: index.html, manifest.webmanifest, sw.js, icons/
